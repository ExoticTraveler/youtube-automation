Privacy Policy

Last updated: October 26, 2026

Exotic Traveler YouTube Automation is an open-source tool that helps users automate parts of their own YouTube publishing workflow.

Google and YouTube Data

The application accesses YouTube data only after the user explicitly grants permission through Google OAuth.

OAuth credentials and tokens used by the local application are stored locally on the user's device. This website does not receive or store those credentials.

Data Use

Authorized YouTube access is used only to perform user-requested functions such as uploading videos, reading upload status, managing captions, updating metadata, and setting thumbnails or other publishing information.

Data Sharing

The project does not sell user data or share Google user data with advertisers.

Website Data Collection

This GitHub Pages website does not itself collect account credentials or YouTube account data.

Contact

Questions about this project can be submitted through the project's GitHub Issues page .
